# Deployment Guide\n\nThis guide covers deployment of the Object Detection Platform to various environments.\n\n## Prerequisites\n\n- Docker & Docker Compose\n- CI/CD platform (GitHub Actions, GitLab CI, etc.)\n- Target cloud provider account\n- SSL/TLS certificates\n\n## Local Development\n\n```bash\ngit checkout rebuild/modern-tech-stack\ndocker-compose up -d\n```\n\n## Staging Deployment\n\n### Docker Compose (VPS/Self-Hosted)\n\n```bash\n# On your VPS/server\ngit clone <repo>\ncd Object-detection-using-Yolov8\ngit checkout rebuild/modern-tech-stack\n\n# Create .env file\ncat > .env << EOF\nPOSTGRES_USER=yolo_user\nPOSTGRES_PASSWORD=<secure_password>\nPOSTGRES_DB=yolo_detection\nDATABASE_URL=postgresql://yolo_user:<secure_password>@postgres:5432/yolo_detection\nREDIS_URL=redis://redis:6379/0\nJWT_SECRET_KEY=<random_secret_key>\nAPI_DOMAIN=api.example.com\nEOF\n\n# Start services\ndocker-compose up -d\n\n# Run database migrations\ndocker-compose exec backend alembic upgrade head\n```\n\n### Nginx Reverse Proxy\n\nCreate `nginx.conf`:\n\n```nginx\nupstream backend {\n    server backend:8000;\n}\n\nupstream frontend {\n    server frontend:3000;\n}\n\nserver {\n    listen 80;\n    server_name api.example.com;\n    \n    client_max_body_size 100M;\n    \n    location / {\n        proxy_pass http://backend;\n        proxy_set_header Host $host;\n        proxy_set_header X-Real-IP $remote_addr;\n        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;\n        proxy_set_header X-Forwarded-Proto $scheme;\n        proxy_http_version 1.1;\n        proxy_set_header Upgrade $http_upgrade;\n        proxy_set_header Connection \"upgrade\";\n    }\n}\n\nserver {\n    listen 80;\n    server_name example.com www.example.com;\n    \n    location / {\n        proxy_pass http://frontend;\n        proxy_set_header Host $host;\n        proxy_set_header X-Real-IP $remote_addr;\n        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;\n        proxy_set_header X-Forwarded-Proto $scheme;\n    }\n}\n```\n\n## Production Deployment\n\n### AWS ECS\n\n1. **Push images to ECR:**\n\n```bash\naws ecr get-login-password | docker login --username AWS --password-stdin <account_id>.dkr.ecr.us-east-1.amazonaws.com\n\ndocker build -t yolo-backend:latest ./backend\ndocker tag yolo-backend:latest <account_id>.dkr.ecr.us-east-1.amazonaws.com/yolo-backend:latest\ndocker push <account_id>.dkr.ecr.us-east-1.amazonaws.com/yolo-backend:latest\n```\n\n2. **Create ECS Cluster:**\n\n```bash\naws ecs create-cluster --cluster-name yolo-detection-prod\n```\n\n### Kubernetes\n\n```bash\nkubectl create namespace yolo-prod\nkubectl apply -f k8s/ -n yolo-prod\n```\n\n## Environment Variables\n\nCreate `.env` file in project root:\n\n```\n# Backend\nDATABASE_URL=postgresql://user:password@localhost:5432/yolo_detection\nREDIS_URL=redis://localhost:6379/0\nJWT_SECRET_KEY=your-secret-key\nENV=development\nDEBUG=True\n\n# Frontend\nVITE_API_URL=http://localhost:8000\n```\n\n## Monitoring\n\n### Prometheus Metrics\n\nEndpoint: `http://localhost:8000/metrics`\n\n### Logs\n\n```bash\n# View backend logs\ndocker-compose logs -f backend\n\n# View frontend logs\ndocker-compose logs -f frontend\n```\n"
